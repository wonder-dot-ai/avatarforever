Training concept and other library paths

The README describes two parallel training branches: full-parameter distribution matching distillation for few-step efficiency, and a lightweight robustness adapter trained with Recovery-oriented Rollout Training. The adapter is composed with the distilled generator at deployment. Training code is not included, so this is documentation context rather than a traced executable graph.

The base pipeline also supports two-stage generation: half-resolution sampling → latent upsampling → full-resolution refinement. The root CLI explicitly selects stage_mode="one-stage" and supplies no upsampler. --fast-infer retains loaded modules on GPU; it is separate from ForeverCache and also defaults to off.
